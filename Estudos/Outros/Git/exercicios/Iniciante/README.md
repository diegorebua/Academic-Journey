# 🎯 Git — Iniciante

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01_configuracao_inicial](./01_configuracao_inicial): Configure nome, e-mail, editor padrão e aliases úteis no Git (git config global).
- [02_init_primeiro_commit](./02_init_primeiro_commit): Inicie um repositório, crie arquivos, faça staging e o primeiro commit.
- [03_status_log_diff](./03_status_log_diff): Explore git status, git log (--oneline, --graph), git diff e git show.
- [04_gitignore](./04_gitignore): Crie um .gitignore completo para um projeto Node.js. Entenda os padrões glob.
- [05_staging_area](./05_staging_area): Entenda a staging area: git add -p para adicionar partes de um arquivo, git reset HEAD.
- [06_branching_basico](./06_branching_basico): Crie branches com git branch e git checkout/switch. Entenda HEAD e as referências.
- [07_merge_fastforward](./07_merge_fastforward): Faça merge de uma feature branch (fast-forward). Veja o histórico resultante.
- [08_merge_commit](./08_merge_commit): Force um merge commit (--no-ff). Compare o histórico com o fast-forward.
- [09_resolucao_conflitos_basica](./09_resolucao_conflitos_basica): Simule um conflito de merge alterando a mesma linha e resolva manualmente.
- [10_stash_basico](./10_stash_basico): Use git stash para salvar mudanças temporárias, trocar de branch e restaurar.
- [11_remote_github](./11_remote_github): Conecte o repositório ao GitHub: git remote add, push, pull e fetch.
- [12_clone_fork](./12_clone_fork): Clone um repositório público e entenda a diferença entre clone e fork.
- [13_pull_request_basico](./13_pull_request_basico): Crie uma feature branch, faça push e abra um Pull Request no GitHub.
- [14_tags_versioning](./14_tags_versioning): Crie tags anotadas e leves para marcar versões do projeto (v1.0.0, v1.1.0).
- [15_amend_commit](./15_amend_commit): Use git commit --amend para corrigir a mensagem ou adicionar arquivos ao último commit.
- [16_gitconfig_aliases](./16_gitconfig_aliases): Configure aliases úteis: git st, git co, git lg, git undo.
- [17_reverter_mudancas](./17_reverter_mudancas): Use git restore para descartar mudanças no working directory e staging.
- [18_branch_upstream](./18_branch_upstream): Configure branches de rastreamento (tracking branches) para push/pull sem argumentos.
- [19_visualizar_historico](./19_visualizar_historico): Use git log com filtros: --author, --since, --grep, --all, -S 'string'.
- [20_arquivo_historico](./20_arquivo_historico): Use git blame para ver quem modificou cada linha e git log -- path para o histórico de um arquivo.
- [21_cherry_pick_simples](./21_cherry_pick_simples): Traga um commit específico de outra branch com git cherry-pick.
- [22_submodulos_basico](./22_submodulos_basico): Adicione um repositório como submódulo e entenda como atualizar e commitar.
- [23_worktree](./23_worktree): Use git worktree para trabalhar em duas branches ao mesmo tempo em diretórios separados.
- [24_bundle_backup](./24_bundle_backup): Crie um backup completo do repositório com git bundle.
- [25_sparse_checkout](./25_sparse_checkout): Use git sparse-checkout para checar apenas parte de um repositório grande.
- [26_commit_message_convention](./26_commit_message_convention): Adote Conventional Commits: feat, fix, docs, chore, refactor, test.
- [27_merge_vs_rebase_conceito](./27_merge_vs_rebase_conceito): Entenda conceitualmente a diferença entre merge e rebase com diagramas.
- [28_git_shortlog](./28_git_shortlog): Use git shortlog -sn para ver a contribuição de cada autor.
- [29_git_describe](./29_git_describe): Use git describe para gerar versões automaticamente baseadas em tags.
- [30_primeiro_open_source](./30_primeiro_open_source): Faça um fork de um repositório open-source, corrija um bug simples e abra um PR.
