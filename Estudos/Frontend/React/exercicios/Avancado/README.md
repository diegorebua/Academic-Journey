# 🎯 React — Avancado

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01_renderizacao_server_side](./01_renderizacao_server_side): Implemente SSR com Next.js: getServerSideProps, getStaticProps e ISR.
- [02_react_server_components](./02_react_server_components): Crie um app com React Server Components (RSC) para reduzir o JavaScript enviado ao cliente.
- [03_concurrent_features](./03_concurrent_features): Use startTransition, useDeferredValue e Suspense para melhorar a responsividade.
- [04_gerenciamento_estado_complexo](./04_gerenciamento_estado_complexo): Compare e implemente o mesmo estado com Redux, Zustand, Jotai e XState.
- [05_micro_frontends_react](./05_micro_frontends_react): Integre múltiplos mini-apps React via Module Federation (Webpack 5).
- [06_design_system](./06_design_system): Construa um design system com componentes base, tokens de design e Storybook.
- [07_performance_profiling_react](./07_performance_profiling_react): Use o React DevTools Profiler para encontrar e corrigir gargalos de renderização.
- [08_suspense_avancado](./08_suspense_avancado): Implemente Suspense com múltiplos níveis, fallbacks e data fetching integrado.
- [09_custom_renderer](./09_custom_renderer): Crie um React Renderer customizado para um alvo diferente do DOM (ex: terminal, canvas).
- [10_reconciler_internos](./10_reconciler_internos): Estude o reconciliador do React: como o Fiber funciona, prioridades e lanes.
- [11_gerenciamento_formulario_avancado](./11_gerenciamento_formulario_avancado): Construa um engine de formulários dinâmicos que renderiza campos a partir de um JSON Schema.
- [12_animacoes_physics](./12_animacoes_physics): Implemente animações baseadas em física com React Spring (molas, inércia).
- [13_3d_react_three_fiber](./13_3d_react_three_fiber): Crie uma cena 3D interativa com React Three Fiber (three.js + React).
- [14_realtime_collaboration](./14_realtime_collaboration): Implemente edição colaborativa em tempo real (ex: editor de texto) com CRDTs e WebSockets.
- [15_ab_testing](./15_ab_testing): Implemente um sistema de A/B testing em tempo de execução para componentes React.
- [16_monorepo_turborepo](./16_monorepo_turborepo): Configure um monorepo com Turborepo, compartilhando componentes entre apps Next.js e Vite.
- [17_edge_rendering](./17_edge_rendering): Deploy a aplicação no edge com Next.js Edge Runtime para latência mínima global.
- [18_streaming_ssr](./18_streaming_ssr): Use Streaming SSR do React 18 para enviar HTML progressivamente ao cliente.
- [19_islands_architecture](./19_islands_architecture): Implemente a Arquitetura de Ilhas com hidratação parcial usando Astro + React.
- [20_accessibility_audit](./20_accessibility_audit): Faça uma auditoria completa de acessibilidade (WCAG 2.1 AA) e corrija todos os problemas.
- [21_security_react](./21_security_react): Identifique e corrija vulnerabilidades XSS, CSRF e dependências inseguras em um app React.
- [22_canvas_react_performance](./22_canvas_react_performance): Crie uma visualização de dados com Canvas API em React com dezenas de milhares de pontos.
- [23_wasm_react](./23_wasm_react): Integre WebAssembly em React para uma tarefa de processamento pesado no cliente.
- [24_redux_advanced_patterns](./24_redux_advanced_patterns): Implemente Entity Adapter, createListenerMiddleware e RTK Query no Redux Toolkit.
- [25_query_normalization](./25_query_normalization): Normalize o cache de dados do React Query para evitar dados desatualizados.
- [26_viewtransition_api](./26_viewtransition_api): Use a View Transition API para animações suaves entre páginas no React.
- [27_signal_based_react](./27_signal_based_react): Implemente um mini framework de Signals que se integra com o ciclo de vida do React.
- [28_shared_element_transition](./28_shared_element_transition): Implemente transições de elemento compartilhado entre rotas (ex: carta de produto que expande).
- [29_offline_first](./29_offline_first): Construa uma aplicação offline-first com sync em background quando a conexão retornar.
- [30_full_stack_nextjs](./30_full_stack_nextjs): Construa um app full-stack com Next.js App Router, Server Actions, Prisma e autenticação Auth.js.
