# 🎯 JavaScript — Intermediario

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01_todo_list_dom](./01_todo_list_dom): Crie uma To-Do List completa no navegador manipulando o DOM: adicionar, editar, remover e marcar como concluído.
- [02_fetch_viacep](./02_fetch_viacep): Consuma a API do ViaCEP, exiba o endereço e salve o histórico de buscas no localStorage.
- [03_jogo_da_velha](./03_jogo_da_velha): Crie um Jogo da Velha completo no navegador com indicação do vencedor e placar.
- [04_carrossel](./04_carrossel): Implemente um carrossel de imagens com auto-play, botões de navegação e dots de posição.
- [05_drag_and_drop](./05_drag_and_drop): Implemente um quadro Kanban simples usando a API de Drag and Drop nativa do HTML5.
- [06_calculadora_avancada](./06_calculadora_avancada): Construa uma calculadora com histórico de operações, suporte a parênteses e memória (M+, M-, MR).
- [07_debounce_throttle](./07_debounce_throttle): Implemente as funções debounce e throttle do zero e demonstre a diferença em um campo de busca.
- [08_event_emitter](./08_event_emitter): Crie um EventEmitter customizado (similar ao do Node.js) com on, off, emit e once.
- [09_promise_all_settled](./09_promise_all_settled): Crie um runner de tarefas que executa várias Promises e trata sucesso/falha de cada uma.
- [10_async_await_retry](./10_async_await_retry): Implemente uma função que tenta executar uma operação assíncrona até N vezes com delay entre as tentativas.
- [11_cache_simples](./11_cache_simples): Crie um sistema de cache em memória com tempo de expiração (TTL) para resultados de funções.
- [12_observer_pattern](./12_observer_pattern): Implemente o padrão de projeto Observer para um sistema de notificações em tempo real.
- [13_lazy_loading](./13_lazy_loading): Implemente Lazy Loading de imagens usando a Intersection Observer API.
- [14_formulario_multistep](./14_formulario_multistep): Crie um formulário multi-etapas com validação em cada step e barra de progresso.
- [15_infinite_scroll](./15_infinite_scroll): Implemente scroll infinito consumindo uma API paginada (ex: JSONPlaceholder).
- [16_dark_mode](./16_dark_mode): Implemente alternância de Dark Mode com preferência salva no localStorage e respeito ao prefers-color-scheme.
- [17_validacao_form](./17_validacao_form): Crie um formulário de cadastro com validação em tempo real de todos os campos (nome, email, CPF, senha forte).
- [18_modulo_pattern](./18_modulo_pattern): Refatore um código procedural para usar o Module Pattern com IIFEs.
- [19_currying](./19_currying): Implemente currying e composição de funções. Crie um pipeline funcional.
- [20_prototype_chain](./20_prototype_chain): Demonstre herança via cadeia de protótipos. Crie classes sem usar a sintaxe ES6 class.
- [21_intersection_observer](./21_intersection_observer): Use a Intersection Observer API para animar elementos conforme entram na viewport (scroll reveal).
- [22_web_workers](./22_web_workers): Mova um cálculo pesado (ex: números primos até 10 milhões) para um Web Worker sem travar a UI.
- [23_indexeddb](./23_indexeddb): Use a IndexedDB para criar um CRUD de contatos offline, sincronizando quando a conexão retornar.
- [24_service_worker](./24_service_worker): Crie um Service Worker básico que cacheia os assets do site e permite acesso offline.
- [25_websocket_chat](./25_websocket_chat): Crie um chat em tempo real simples usando WebSockets nativos (sem bibliotecas).
- [26_canvas_jogo](./26_canvas_jogo): Crie um jogo simples no Canvas (ex: Pong ou Snake) com game loop e detecção de colisão.
- [27_clone_trello](./27_clone_trello): Crie um clone simplificado do Trello com colunas e cartões arrastáveis, persistindo no localStorage.
- [28_regex_parser](./28_regex_parser): Crie um mini parser de Markdown que converte **negrito**, *itálico* e # Títulos para HTML usando Regex.
- [29_rate_limiter](./29_rate_limiter): Implemente um Rate Limiter no cliente que bloqueia requisições duplicadas em um intervalo de tempo.
- [30_virtual_dom](./30_virtual_dom): Implemente um Virtual DOM minimalista com funções createElement, diff e patch.
