# 🎯 JavaScript — Avancado

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01_spa_roteador](./01_spa_roteador): Crie um roteador de Single Page Application do zero usando a History API, com rotas dinâmicas e guards.
- [02_reatividade_vue_like](./02_reatividade_vue_like): Implemente um sistema de reatividade simples similar ao Vue 2, usando Object.defineProperty e watchers.
- [03_state_machine](./03_state_machine): Implemente uma Máquina de Estados Finitos (FSM) genérica e use-a para modelar um carrinho de compras.
- [04_interpreter](./04_interpreter): Crie um interpretador de uma linguagem de script simples (variáveis, ifs, loops) usando um lexer e parser.
- [05_promise_implementation](./05_promise_implementation): Implemente sua própria Promise do zero, compatível com a especificação Promises/A+.
- [06_rx_observable](./06_rx_observable): Implemente um mini RxJS com Observable, Subject, e os operadores map, filter, mergeMap.
- [07_module_bundler](./07_module_bundler): Crie um module bundler simplificado (inspirado no Webpack) que resolve imports/requires e gera um bundle.
- [08_template_engine](./08_template_engine): Crie um motor de templates com suporte a variáveis {{var}}, loops {{#each}} e condicionais {{#if}}.
- [09_memoizacao_avancada](./09_memoizacao_avancada): Implemente memoização com suporte a argumentos complexos (objetos e arrays), usando serialização e WeakMap.
- [10_proxy_interceptor](./10_proxy_interceptor): Use a API Proxy do JavaScript para criar um framework de validação de objetos declarativo.
- [11_framework_reativo](./11_framework_reativo): Crie um micro-framework de UI reativo com componentes, props, estado e re-renderização eficiente.
- [12_compilador_expressoes](./12_compilador_expressoes): Implemente um compilador de expressões matemáticas que converte infix para postfix e depois avalia.
- [13_scheduler_tarefas](./13_scheduler_tarefas): Crie um scheduler de tarefas assíncronas com prioridades, filas e suporte a cancelamento.
- [14_transpiler_basico](./14_transpiler_basico): Crie um transpiler que converte arrow functions e template literals para ES5.
- [15_type_system](./15_type_system): Implemente um sistema de tipos em runtime para JavaScript, validando tipos primitivos, objetos e genéricos.
- [16_event_sourcing](./16_event_sourcing): Implemente um sistema simples de Event Sourcing onde o estado é derivado de uma sequência de eventos imutáveis.
- [17_cqrs_pattern](./17_cqrs_pattern): Implemente o padrão CQRS (Command Query Responsibility Segregation) em uma aplicação de gerenciamento de estoque.
- [18_vm_javascript](./18_vm_javascript): Crie uma máquina virtual baseada em bytecode que executa um subconjunto de operações JavaScript.
- [19_circuit_breaker](./19_circuit_breaker): Implemente o padrão Circuit Breaker para chamadas de API, com estados Closed, Open e Half-Open.
- [20_dependency_injection](./20_dependency_injection): Crie um contêiner de Injeção de Dependências simples que resolve dependências automaticamente.
- [21_lru_cache](./21_lru_cache): Implemente um cache LRU (Least Recently Used) usando um Map e uma lista duplamente encadeada.
- [22_diff_algorithm](./22_diff_algorithm): Implemente o algoritmo de diff de strings/arrays (similar ao que o Git usa para mostrar diferenças).
- [23_csp_interpreter](./23_csp_interpreter): Crie um interpretador de Communicating Sequential Processes (CSP) com channels e goroutines simuladas.
- [24_jit_compiler](./24_jit_compiler): Simule um compilador JIT simples que otimiza funções puras chamadas repetidamente.
- [25_reactive_db](./25_reactive_db): Crie um banco de dados reativo em memória que notifica assinantes quando os dados mudam (similar ao Firebase Realtime DB).
- [26_ast_transformer](./26_ast_transformer): Crie um transformador de AST (Abstract Syntax Tree) que refatora automaticamente código JavaScript.
- [27_concorrencia_promises](./27_concorrencia_promises): Implemente Promise.all, Promise.race, Promise.any e Promise.allSettled do zero.
- [28_signal_system](./28_signal_system): Implemente um sistema de Signals (similar ao SolidJS) com computeds e effects automáticos.
- [29_wasm_integration](./29_wasm_integration): Crie um módulo WebAssembly em C/Rust e integre-o com JavaScript para um cálculo intensivo.
- [30_micro_frontend](./30_micro_frontend): Implemente a arquitetura de Micro Frontends com module federation manual e comunicação entre apps.
