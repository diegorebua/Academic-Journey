# 🎯 NodeJS — Iniciante

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01_hello_server](./01_hello_server): Crie um servidor HTTP nativo que responde 'Olá, Mundo!' em diferentes rotas.
- [02_leitura_arquivo](./02_leitura_arquivo): Leia um arquivo .txt com fs.readFile e escreva o resultado processado em outro arquivo.
- [03_cli_argumentos](./03_cli_argumentos): Crie um script CLI que lê argumentos do process.argv e executa ações diferentes.
- [04_modulos_customizados](./04_modulos_customizados): Crie módulos separados e importe-os usando require e ES Modules (import/export).
- [05_path_os](./05_path_os): Use os módulos path e os para exibir informações do sistema e manipular caminhos.
- [06_env_dotenv](./06_env_dotenv): Configure variáveis de ambiente com .env usando dotenv. Nunca exponha segredos no código.
- [07_readline_interativo](./07_readline_interativo): Crie um programa interativo usando readline que simula um menu de opções.
- [08_events_emitter](./08_events_emitter): Use o EventEmitter do Node.js para criar um sistema de eventos customizado.
- [09_timers_node](./09_timers_node): Demonstre setTimeout, setInterval, setImmediate e process.nextTick com suas diferenças.
- [10_buffers_streams_basico](./10_buffers_streams_basico): Leia um arquivo usando Streams (fs.createReadStream) e processe linha por linha.
- [11_http_request_sem_lib](./11_http_request_sem_lib): Faça uma requisição HTTP GET para uma API pública usando apenas o módulo http/https nativo.
- [12_child_process](./12_child_process): Execute um comando do sistema (ex: ls, pwd) usando child_process.exec e capture a saída.
- [13_crypto_hash](./13_crypto_hash): Use o módulo crypto para gerar hashes SHA-256 de strings e comparar de forma segura.
- [14_zlib_compressao](./14_zlib_compressao): Comprima e descomprima um arquivo usando zlib (gzip) via Streams.
- [15_url_parse](./15_url_parse): Parse e manipule URLs usando o módulo url nativo. Extraia pathname, query params e hostname.
- [16_json_manipulacao](./16_json_manipulacao): Leia um arquivo JSON grande, filtre e transforme os dados, e escreva um novo arquivo JSON.
- [17_glob_padroes](./17_glob_padroes): Use glob patterns para listar arquivos recursivamente em um diretório.
- [18_watch_arquivos](./18_watch_arquivos): Use fs.watch para monitorar mudanças em um arquivo e reagir automaticamente.
- [19_calculator_cli](./19_calculator_cli): Crie uma calculadora de linha de comando que funciona como uma calculadora de pilha (RPN).
- [20_concurrent_downloads](./20_concurrent_downloads): Baixe múltiplos arquivos simultaneamente usando Promise.all e streams.
- [21_server_estatico](./21_server_estatico): Crie um servidor de arquivos estáticos que serve HTML, CSS e JS com os Content-Types corretos.
- [22_logger_personalizado](./22_logger_personalizado): Crie um logger com níveis (DEBUG, INFO, WARN, ERROR) que escreve em arquivo e console.
- [23_config_manager](./23_config_manager): Crie um gerenciador de configurações que lê de arquivo JSON, variáveis de ambiente e argumentos CLI.
- [24_task_runner](./24_task_runner): Crie um task runner simples que executa scripts definidos em um arquivo de configuração YAML/JSON.
- [25_ping_hosts](./25_ping_hosts): Crie um script que pinga uma lista de hosts em paralelo e reporta quais estão online.
- [26_gerador_relatorio](./26_gerador_relatorio): Leia um CSV de vendas e gere um relatório em TXT com totais por categoria.
- [27_cli_todo](./27_cli_todo): Crie uma CLI de To-Do List que persiste dados em um arquivo JSON local.
- [28_validador_json](./28_validador_json): Crie um validador de arquivos JSON que verifica estrutura contra um schema definido.
- [29_conversor_encoding](./29_conversor_encoding): Converta arquivos entre encodings (UTF-8, Latin-1) usando Buffer e streams.
- [30_tcp_socket](./30_tcp_socket): Crie um servidor e cliente TCP simples usando o módulo net do Node.js.
