# 🎯 TypeScript — Intermediario

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01_generic_repository](./01_generic_repository): Crie um repositório genérico Repository<T> com métodos findById, findAll, save, delete.
- [02_utility_types_avancados](./02_utility_types_avancados): Pratique Pick, Omit, Exclude, Extract, NonNullable, ReturnType e Parameters.
- [03_infer_keyword](./03_infer_keyword): Use infer dentro de Conditional Types para extrair tipos de Promises, arrays e funções.
- [04_decorators_avancados](./04_decorators_avancados): Implemente decorators de classe, método, propriedade e parâmetro para um framework de validação.
- [05_mixins](./05_mixins): Implemente o padrão de Mixins para compor comportamentos reutilizáveis em classes.
- [06_builder_pattern_ts](./06_builder_pattern_ts): Implemente o padrão Builder com TypeScript para construir objetos complexos de forma fluente e tipada.
- [07_zod_validacao](./07_zod_validacao): Use a biblioteca Zod para validar e inferir tipos de dados de uma API externa.
- [08_api_tipada](./08_api_tipada): Crie uma camada de API totalmente tipada usando fetch genérico e tipos de resposta da API.
- [09_react_typescript](./09_react_typescript): Configure um projeto React + TypeScript. Tipe props, state, eventos e refs.
- [10_redux_typescript](./10_redux_typescript): Configure Redux Toolkit com TypeScript, tipando actions, reducers e seletores.
- [11_generic_event_emitter](./11_generic_event_emitter): Crie um EventEmitter genérico e tipado onde os nomes dos eventos e os payloads são inferidos.
- [12_type_safe_router](./12_type_safe_router): Implemente um roteador type-safe onde as rotas, parâmetros e queries são totalmente tipados.
- [13_factory_pattern_ts](./13_factory_pattern_ts): Implemente o padrão Factory com TypeScript para criar instâncias de objetos de forma tipada.
- [14_strategy_pattern_ts](./14_strategy_pattern_ts): Implemente o padrão Strategy para um sistema de pagamento (Cartão, PIX, Boleto) com TypeScript.
- [15_result_type](./15_result_type): Crie um tipo Result<T, E> (similar ao Rust) e use-o para tratamento de erros sem exceções.
- [16_either_monad](./16_either_monad): Implemente a mônada Either para encadear operações que podem falhar de forma tipada.
- [17_branded_types](./17_branded_types): Use Branded Types para tornar tipos primitivos incompatíveis (UserId não aceita ProductId).
- [18_opaque_types](./18_opaque_types): Implemente Opaque Types para encapsular lógica de negócio e evitar mistura de IDs.
- [19_phantom_types](./19_phantom_types): Use Phantom Types para adicionar informações de tipo em tempo de compilação sem custo em runtime.
- [20_typescript_compiler_api](./20_typescript_compiler_api): Explore a API do compilador TypeScript para ler um arquivo .ts e extrair informações de tipos.
- [21_template_literal_avancado](./21_template_literal_avancado): Combine Template Literal Types com Mapped Types para criar tipos de eventos (onClick → 'click').
- [22_recursive_types](./22_recursive_types): Crie Recursive Types para representar estruturas de árvore e JSON aninhado.
- [23_variadic_tuple_types](./23_variadic_tuple_types): Use Variadic Tuple Types para implementar funções pipe e compose completamente tipadas.
- [24_satisfies_operator](./24_satisfies_operator): Demonstre casos de uso do operador satisfies para validar configurações e literais.
- [25_using_declaration](./25_using_declaration): Use a declaração using (TC39 proposal) com Symbol.dispose para gerenciamento de recursos.
- [26_ts_monorepo](./26_ts_monorepo): Configure um monorepo com TypeScript usando Project References e workspaces.
- [27_strict_mode_erros](./27_strict_mode_erros): Ative o modo strict completo e corrija todos os erros em um código legado problemático.
- [28_test_tipagem](./28_test_tipagem): Use a biblioteca tsd ou expect-type para escrever testes de tipagem de TypeScript.
- [29_orm_tipado](./29_orm_tipado): Use Prisma ou TypeORM com TypeScript para criar, ler, atualizar e deletar registros tipados.
- [30_dts_gerador](./30_dts_gerador): Gere arquivos .d.ts para uma biblioteca JavaScript existente sem TypeScript.
