# 🎯 TypeScript — Avancado

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01_hkt_higher_kinded](./01_hkt_higher_kinded): Simule Higher-Kinded Types em TypeScript usando técnicas de encoding de tipos.
- [02_type_level_arithmetic](./02_type_level_arithmetic): Realize aritmética no nível de tipos usando Recursive Types e Tuple manipulation.
- [03_peano_numbers](./03_peano_numbers): Implemente os números de Peano no sistema de tipos do TypeScript (soma, comparação).
- [04_type_safe_sql](./04_type_safe_sql): Crie um query builder SQL completamente tipado onde erros de coluna/tabela são detectados em compilação.
- [05_type_safe_form](./05_type_safe_form): Implemente um sistema de formulários type-safe onde cada campo, validação e erro são inferidos automaticamente.
- [06_ts_plugin](./06_ts_plugin): Crie um plugin do compilador TypeScript (Language Service Plugin) para adicionar regras customizadas.
- [07_generic_di_container](./07_generic_di_container): Implemente um contêiner de Injeção de Dependências genérico e completamente tipado.
- [08_dependent_types_simulado](./08_dependent_types_simulado): Simule Dependent Types em TypeScript (ex: Array com tamanho fixo no tipo).
- [09_effect_system](./09_effect_system): Implemente um sistema de efeitos tipado (IO monad) que rastreia efeitos colaterais no tipo.
- [10_abstract_algebra](./10_abstract_algebra): Modele estruturas da álgebra abstrata (Monoid, Functor, Applicative) em TypeScript.
- [11_lens_optics](./11_lens_optics): Implemente Lenses e Prisms para atualização imutável e type-safe de estruturas aninhadas.
- [12_free_monad](./12_free_monad): Implemente a Free Monad em TypeScript para separar definição de programa de interpretação.
- [13_type_safe_state_machine](./13_type_safe_state_machine): Crie uma Máquina de Estados onde as transições inválidas causam erros de compilação.
- [14_coroutine_generator_types](./14_coroutine_generator_types): Tipo generators e coroutines complexas usando infer e Recursive Types.
- [15_ts_to_json_schema](./15_ts_to_json_schema): Crie uma ferramenta que converte tipos TypeScript em JSON Schema automaticamente.
- [16_compiletime_assertions](./16_compiletime_assertions): Use tsd e Template Literal Types para escrever assertions de tipo em tempo de compilação.
- [17_metaprogramming_ts](./17_metaprogramming_ts): Explore metaprogramação com Conditional Types e Mapped Types para criar APIs genéricas.
- [18_pattern_matching_ts](./18_pattern_matching_ts): Implemente Pattern Matching seguro em TypeScript usando a biblioteca ts-pattern.
- [19_nominal_typing](./19_nominal_typing): Implemente Nominal Typing robusto em uma linguagem que é estruturalmente tipada.
- [20_arrow_types](./20_arrow_types): Use FlowType-style type annotations convertidas para TypeScript em uma codebase real.
- [21_ts_eslint_rules](./21_ts_eslint_rules): Escreva regras ESLint customizadas para TypeScript usando @typescript-eslint/utils.
- [22_transformations_api](./22_transformations_api): Crie transformações de tipos que convertem DTO ↔ Domain Model ↔ Persistence Model.
- [23_advanced_inference](./23_advanced_inference): Domine inferência de tipos em contextos complexos: mapped types aninhados, infer em unions.
- [24_ts_interpreter](./24_ts_interpreter): Implemente um interpretador de um subconjunto do TypeScript usando apenas o sistema de tipos.
- [25_typed_event_bus](./25_typed_event_bus): Implemente um Event Bus totalmente tipado onde cada tópico tem um payload inferido.
- [26_dsl_type_level](./26_dsl_type_level): Crie uma DSL (Domain Specific Language) que funciona no nível de tipos do TypeScript.
- [27_type_safe_api_client](./27_type_safe_api_client): Implemente um cliente de API que infere automaticamente os tipos de resposta a partir de uma definição OpenAPI.
- [28_monad_transformers](./28_monad_transformers): Implemente Monad Transformers para compor efeitos como Maybe + IO + Either.
- [29_ts_kernel](./29_ts_kernel): Crie uma biblioteca de utilitários de tipos TypeScript publicável no npm com tipos complexos.
- [30_full_type_system](./30_full_type_system): Implemente um sistema de tipos simples (como o Hindley-Milner) usando apenas o sistema de tipos do TypeScript.
