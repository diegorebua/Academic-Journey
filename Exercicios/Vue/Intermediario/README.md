# 🎯 Vue — Intermediario

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01_pinia_loja](./01_pinia_loja): Configure o Pinia e crie uma store para um carrinho de compras com persist.
- [02_vue_router_avancado](./02_vue_router_avancado): Configure rotas aninhadas, guards de navegação e rotas com parâmetros dinâmicos.
- [03_composables_custom](./03_composables_custom): Crie composables reutilizáveis: useFetch, useDebounce, useIntersectionObserver.
- [04_formulario_veevalidate](./04_formulario_veevalidate): Implemente validação de formulário robusta com VeeValidate e Yup.
- [05_componentes_async](./05_componentes_async): Use defineAsyncComponent para carregar componentes sob demanda com Suspense.
- [06_teleport_vue](./06_teleport_vue): Use o componente <Teleport> para renderizar modais e tooltips fora da hierarquia do DOM.
- [07_slots_avancados](./07_slots_avancados): Use named slots, scoped slots e o padrão renderless para componentes ultra-flexíveis.
- [08_diretivas_customizadas](./08_diretivas_customizadas): Crie diretivas personalizadas v-focus, v-click-outside e v-tooltip.
- [09_plugin_vue](./09_plugin_vue): Crie e registre um plugin Vue que adiciona propriedades globais e filtros.
- [10_ssr_nuxt_basico](./10_ssr_nuxt_basico): Configure um projeto Nuxt.js com SSR, páginas, layouts e fetch de dados no servidor.
- [11_testes_vitest](./11_testes_vitest): Escreva testes unitários com Vitest e Vue Test Utils para componentes e stores Pinia.
- [12_storybook_vue](./12_storybook_vue): Configure Storybook e crie stories para seus componentes Vue.
- [13_graficos_vue_chartjs](./13_graficos_vue_chartjs): Crie dashboards com gráficos usando Vue Chart.js (Chart.js wrapper).
- [14_tabela_datatables](./14_tabela_datatables): Implemente uma tabela com paginação, ordenação e filtro server-side.
- [15_maps_leaflet_vue](./15_maps_leaflet_vue): Integre Leaflet com Vue para exibir mapas com markers dinâmicos.
- [16_i18n_vue](./16_i18n_vue): Configure internacionalização com vue-i18n e suporte a múltiplos idiomas.
- [17_real_time_vue](./17_real_time_vue): Integre WebSockets via Socket.io para notificações em tempo real em Vue.
- [18_autenticacao_vue](./18_autenticacao_vue): Implemente autenticação JWT com guarda de rotas e refresh de token automático.
- [19_upload_vue](./19_upload_vue): Implemente upload de arquivos com preview usando vue-dropzone.
- [20_pdf_export](./20_pdf_export): Gere PDFs de componentes Vue usando jsPDF e html2canvas.
- [21_kanban_pinia](./21_kanban_pinia): Crie um quadro Kanban com drag-and-drop gerenciado pelo Pinia.
- [22_editor_wysiwyg](./22_editor_wysiwyg): Integre um editor WYSIWYG (ex: Quill ou TipTap) em um formulário Vue.
- [23_pwa_vue](./23_pwa_vue): Converta o app Vue em uma PWA com Service Worker usando vite-plugin-pwa.
- [24_seo_nuxt](./24_seo_nuxt): Configure meta tags, Open Graph e sitemap no Nuxt.js para SEO.
- [25_monorepo_vue](./25_monorepo_vue): Configure um monorepo com múltiplos apps Vue compartilhando componentes.
- [26_renderizacao_virtual](./26_renderizacao_virtual): Implemente uma lista virtual com vue-virtual-scroller.
- [27_state_machine_xstate](./27_state_machine_xstate): Use XState com Vue para gerenciar fluxos complexos (autenticação, wizard).
- [28_animations_gsap](./28_animations_gsap): Integrate GSAP (GreenSock) com Vue para animações de alto desempenho.
- [29_composable_usefetch_avancado](./29_composable_usefetch_avancado): Crie um composable useFetch avançado com cache, abort, retentativas e dedupliacação.
- [30_design_system_vue](./30_design_system_vue): Construa um design system Vue com componentes documentados e publicável no npm.
