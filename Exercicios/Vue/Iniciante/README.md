# 🎯 Vue — Iniciante

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01_contador_vue](./01_contador_vue): Crie um contador simples com ref() da Composition API.
- [02_lista_tarefas_vue](./02_lista_tarefas_vue): To-Do List com v-model, v-for e v-if usando Composition API.
- [03_formulario_controlado](./03_formulario_controlado): Crie um formulário controlado com v-model em inputs, selects e checkboxes.
- [04_props_emits](./04_props_emits): Crie componentes pai e filho passando dados via props e respondendo via emits.
- [05_computed_properties](./05_computed_properties): Use computed() para calcular valores derivados de forma reativa.
- [06_watchers](./06_watchers): Use watch e watchEffect para reagir a mudanças de estado com efeitos colaterais.
- [07_lifecycle_hooks](./07_lifecycle_hooks): Demonstre o uso de onMounted, onUpdated e onUnmounted com exemplos práticos.
- [08_v_model_custom](./08_v_model_custom): Crie um componente Input customizado que funciona com v-model externo.
- [09_slots_simples](./09_slots_simples): Use slots para criar componentes contêiner flexíveis (Card, Modal, Layout).
- [10_diretivas_vue](./10_diretivas_vue): Use v-show, v-if, v-else, v-for, v-bind e v-on em exemplos variados.
- [11_template_refs](./11_template_refs): Use template refs para acessar elementos do DOM e métodos de componentes filhos.
- [12_provide_inject](./12_provide_inject): Use provide/inject para compartilhar dados entre componentes sem props drilling.
- [13_reactive_object](./13_reactive_object): Compare ref() e reactive() e entenda quando usar cada um.
- [14_consumir_api_axios](./14_consumir_api_axios): Consuma a API do JSONPlaceholder usando Axios dentro do onMounted.
- [15_galeria_imagens](./15_galeria_imagens): Crie uma galeria de imagens com lightbox usando componentes Vue.
- [16_filtros_busca](./16_filtros_busca): Crie uma lista filtrável com computed properties e um campo de busca.
- [17_carrinho_simples](./17_carrinho_simples): Implemente um carrinho de compras simples com reactividade e total calculado.
- [18_dark_mode_vue](./18_dark_mode_vue): Implemente alternância de tema claro/escuro com provide/inject.
- [19_animacoes_transicao](./19_animacoes_transicao): Use as diretivas <Transition> e <TransitionGroup> para animar listas e componentes.
- [20_validacao_formulario](./20_validacao_formulario): Valide um formulário manualmente e depois com a biblioteca Vuelidate.
- [21_roteamento_basico](./21_roteamento_basico): Configure o Vue Router com rotas simples e navegação entre páginas.
- [22_paginacao_lista](./22_paginacao_lista): Implemente paginação manual em uma lista de dados.
- [23_barra_progresso_vue](./23_barra_progresso_vue): Crie uma barra de progresso animada controlada por estado reativo.
- [24_accordion_vue](./24_accordion_vue): Implemente um Accordion com componentes aninhados.
- [25_breadcrumb_router](./25_breadcrumb_router): Crie um componente de Breadcrumb dinâmico integrado com o Vue Router.
- [26_infinite_scroll_vue](./26_infinite_scroll_vue): Implemente scroll infinito usando Intersection Observer e dados de uma API.
- [27_drag_drop_simples](./27_drag_drop_simples): Implemente drag-and-drop simples usando eventos de drag nativos do HTML5.
- [28_clipboard_api](./28_clipboard_api): Crie um botão de 'Copiar para área de transferência' com feedback visual.
- [29_composable_uselocalstorage](./29_composable_uselocalstorage): Crie um composable useLocalStorage que sincroniza estado com o localStorage.
- [30_mini_portfolio_vue](./30_mini_portfolio_vue): Crie um mini portfólio pessoal com Vue.js: seções de Sobre, Projetos e Contato.
