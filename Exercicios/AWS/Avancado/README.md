# 🎯 AWS — Avancado

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01_landing_zone](./01_landing_zone): Configure uma Landing Zone multi-conta com AWS Control Tower e Account Factory.
- [02_service_control_policies](./02_service_control_policies): Implemente SCPs para restringir ações em toda a organização (ex: bloquear regiões não aprovadas).
- [03_terraform_modules](./03_terraform_modules): Crie módulos Terraform reutilizáveis para VPC, ECS e RDS com variáveis e outputs.

- [05_cdk_infraestrutura](./05_cdk_infraestrutura): Provisione uma infraestrutura completa usando AWS CDK em TypeScript.
- [06_serverless_avancado](./06_serverless_avancado): Crie uma aplicação Serverless complexa com API Gateway, Lambda, DynamoDB e SQS com SAM.
- [07_ecs_service_mesh](./07_ecs_service_mesh): Configure AWS App Mesh como service mesh para comunicação entre serviços ECS.
- [08_eks_kubernetes](./08_eks_kubernetes): Provisione um cluster EKS, deploye uma aplicação e configure HPA.
- [09_multi_region_active_active](./09_multi_region_active_active): Projete e implemente um sistema Active-Active multi-região com Route 53 geolocation routing.
- [10_chaos_engineering_aws](./10_chaos_engineering_aws): Use o AWS Fault Injection Service (FIS) para injetar falhas e testar resiliência.
- [11_data_lake_s3](./11_data_lake_s3): Construa um Data Lake no S3 com camadas Bronze, Silver e Gold e governança com Glue.
- [12_realtime_analytics](./12_realtime_analytics): Implemente analytics em tempo real com Kinesis Data Streams → Flink → OpenSearch.
- [13_ml_sagemaker](./13_ml_sagemaker): Treine e faça deploy de um modelo de ML simples com SageMaker Pipelines.
- [14_bedrock_integration](./14_bedrock_integration): Integre o Amazon Bedrock (LLMs) em uma aplicação serverless para geração de texto.
- [15_zero_trust_aws](./15_zero_trust_aws): Implemente Zero Trust na AWS: mTLS, Verified Access e least-privilege estrito.
- [16_supply_chain_security](./16_supply_chain_security): Configure assinatura de imagens Docker com Notary e verificação no ECR.
- [17_vpc_lattice](./17_vpc_lattice): Use o VPC Lattice para comunicação segura e simplificada entre serviços.
- [18_graviton_arm](./18_graviton_arm): Migre cargas de trabalho para instâncias Graviton3 (ARM) e meça a economia de custo.
- [19_finops_avancado](./19_finops_avancado): Implemente FinOps: tagging strategy, chargeback reports e automação de rightsizing.
- [20_well_architected_remediacao](./20_well_architected_remediacao): Realize um Well-Architected Review completo e implemente os 10 principais remediações.
- [21_security_hub_siem](./21_security_hub_siem): Centralize alertas de segurança com Security Hub e integre com um SIEM (ex: Splunk).
- [22_custom_lens](./22_custom_lens): Crie um Custom Lens no Well-Architected Tool para as especificidades da sua empresa.
- [23_config_remediation](./23_config_remediation): Configure remediação automática no AWS Config com SSM Automation Documents.
- [24_private_api_gateway](./24_private_api_gateway): Configure um API Gateway privado acessível apenas dentro da VPC via VPC Endpoint.
- [25_transit_gateway](./25_transit_gateway): Configure o Transit Gateway para conectar múltiplas VPCs e redes on-premises.
- [26_direct_connect_simulado](./26_direct_connect_simulado): Simule uma conexão Direct Connect usando VPN como failover em uma arquitetura híbrida.
- [27_rds_proxy](./27_rds_proxy): Configure o RDS Proxy para pooling de conexões e failover mais rápido.
- [28_aurora_serverless](./28_aurora_serverless): Use Aurora Serverless v2 e explore seu scaling automático e global database.
- [29_memorydb_redis](./29_memorydb_redis): Migre do ElastiCache Redis para o MemoryDB e explore a durabilidade com Multi-AZ.
- [30_architecture_review_completo](./30_architecture_review_completo): Proponha e documente a arquitetura completa de um sistema de e-commerce de alta escala na AWS.
