# 🎯 Go — Iniciante

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01_hello_world](./01_hello_world): Escreva um programa que imprime 'Olá, Mundo!' e lê o nome do usuário com fmt.Scan.
- [02_tipos_variaveis](./02_tipos_variaveis): Declare variáveis com todos os tipos básicos do Go: int, float64, string, bool, byte, rune.
- [03_estruturas_controle](./03_estruturas_controle): Use if/else, for e switch em exemplos práticos (FizzBuzz, calculadora de notas).
- [04_funcoes_basicas](./04_funcoes_basicas): Crie funções com múltiplos retornos. Implemente troca de valores e divisão com resto.
- [05_arrays_slices](./05_arrays_slices): Diferenças entre arrays e slices. Manipule slices com append, copy e slice expressions.
- [06_maps_basicos](./06_maps_basicos): Crie e manipule maps. Conte frequência de palavras em um texto.
- [07_structs_metodos](./07_structs_metodos): Crie structs para Formas (Círculo, Retângulo) e métodos para calcular área e perímetro.
- [08_interfaces_basicas](./08_interfaces_basicas): Defina uma interface Animal com métodos Falar() e Mover(). Implemente com Cachorro e Pássaro.
- [09_ponteiros](./09_ponteiros): Entenda ponteiros em Go: desreferenciar, passar por ponteiro e quando usar.
- [10_tratamento_erros](./10_tratamento_erros): Implemente tratamento de erros idiomático com error, fmt.Errorf e errors.Is/As.
- [11_goroutine_simples](./11_goroutine_simples): Crie goroutines simples com go func() e sincronize com WaitGroup.
- [12_channels_basicos](./12_channels_basicos): Crie channels buffered e unbuffered para comunicar goroutines.
- [13_defer_panic_recover](./13_defer_panic_recover): Demonstre defer para limpeza de recursos, e panic/recover para situações excepcionais.
- [14_leitura_arquivo](./14_leitura_arquivo): Leia um arquivo texto linha por linha usando bufio.Scanner.
- [15_escrita_arquivo](./15_escrita_arquivo): Escreva dados em arquivo usando os.WriteFile e bufio.Writer.
- [16_conversao_tipos](./16_conversao_tipos): Pratique conversões entre int, float64, string e []byte.
- [17_fibonacci_go](./17_fibonacci_go): Gere a sequência de Fibonacci usando iteração e depois com goroutines e channels.
- [18_ordenacao_slice](./18_ordenacao_slice): Ordene slices de strings, ints e structs usando sort.Slice e sort.SliceStable.
- [19_manipulacao_string](./19_manipulacao_string): Use strings.Builder, strings.Split, strings.Join e regexp para processar textos.
- [20_json_marshal_unmarshal](./20_json_marshal_unmarshal): Serialize e desserialize structs Go para/de JSON. Trate campos opcionais.
- [21_calculator_cli_go](./21_calculator_cli_go): Crie uma calculadora de linha de comando usando os.Args e fmt.Sscanf.
- [22_validador_cpf_go](./22_validador_cpf_go): Implemente a validação de CPF em Go usando apenas operações matemáticas.
- [23_contagem_palavras](./23_contagem_palavras): Leia um arquivo de texto e exiba as 10 palavras mais frequentes.
- [24_gerador_senha_go](./24_gerador_senha_go): Crie um gerador de senhas aleatórias usando crypto/rand.
- [25_http_get_simples](./25_http_get_simples): Faça uma requisição HTTP GET usando net/http e processe a resposta JSON.
- [26_busca_binaria_go](./26_busca_binaria_go): Implemente busca binária e linear e compare usando benchmarks com testing.B.
- [27_fibonacci_memo_go](./27_fibonacci_memo_go): Implemente Fibonacci com memoização usando map e com closures.
- [28_pilha_fila_go](./28_pilha_fila_go): Implemente Pilha e Fila em Go usando slices.
- [29_anagrama_go](./29_anagrama_go): Verifique se duas strings são anagramas usando runas para suporte a Unicode.
- [30_temperatura_converter_go](./30_temperatura_converter_go): Crie um conversor de temperatura CLI que aceita bandeiras com flag package.
