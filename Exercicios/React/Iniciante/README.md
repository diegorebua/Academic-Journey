# 🎯 React — Iniciante

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01_contador](./01_contador): Crie um componente de contador com useState: incrementar, decrementar e resetar.
- [02_lista_de_tarefas](./02_lista_de_tarefas): To-Do List simples: adicionar, remover e marcar tarefas como concluídas.
- [03_renderizacao_listas](./03_renderizacao_listas): Renderize uma lista de itens de um array com .map() usando keys corretas.
- [04_formulario_basico](./04_formulario_basico): Crie um formulário controlado com inputs de texto, select e checkbox.
- [05_condicional_render](./05_condicional_render): Renderize componentes condicionalmente usando ternário, &&  e funções.
- [06_props_basico](./06_props_basico): Passe props entre componentes pai e filho. Use PropTypes ou TypeScript para tipagem.
- [07_eventos_basico](./07_eventos_basico): Trate eventos de clique, input e submit de forma idiomática no React.
- [08_estilo_css](./08_estilo_css): Aplique estilos com CSS Modules, Styled Components e inline styles. Compare as abordagens.
- [09_useEffect_basico](./09_useEffect_basico): Use useEffect para buscar dados de uma API ao montar o componente.
- [10_componente_relogio](./10_componente_relogio): Crie um relógio que atualiza a cada segundo usando useState e useEffect com limpeza.
- [11_galeria_fotos](./11_galeria_fotos): Crie uma galeria de fotos consumindo a API do Unsplash com lightbox ao clicar.
- [12_formulario_cadastro](./12_formulario_cadastro): Formulário de cadastro com campos de nome, e-mail, senha e confirmação de senha.
- [13_rating_estrelas](./13_rating_estrelas): Crie um componente de avaliação com estrelas clicáveis e hover.
- [14_accordion](./14_accordion): Implemente um Accordion (sanfona) com múltiplos painéis que abrem e fecham.
- [15_barra_progresso](./15_barra_progresso): Crie uma barra de progresso animada que pode ser controlada por props.
- [16_carousel_simples](./16_carousel_simples): Implemente um carrossel de imagens com botões de navegação e auto-play.
- [17_modal_dialog](./17_modal_dialog): Crie um componente Modal reutilizável com portal para renderizar fora da hierarquia.
- [18_tooltip](./18_tooltip): Crie um componente Tooltip que aparece ao hoverar um elemento.
- [19_dropdown_select](./19_dropdown_select): Crie um componente Select customizado com busca e opções dinâmicas.
- [20_tabs_navegacao](./20_tabs_navegacao): Implemente um componente Tabs com navegação e conteúdo dinâmico.
- [21_lazy_componente](./21_lazy_componente): Use React.lazy e Suspense para carregar componentes pesados sob demanda.
- [22_error_boundary](./22_error_boundary): Crie um Error Boundary que exibe uma UI de fallback quando um componente filho lança um erro.
- [23_fragment_portal](./23_fragment_portal): Demonstre o uso de React.Fragment e ReactDOM.createPortal.
- [24_ref_dom](./24_ref_dom): Use useRef para acessar e manipular elementos do DOM diretamente (foco, scroll).
- [25_forward_ref](./25_forward_ref): Implemente forwardRef em um componente Input para expor o ref ao componente pai.
- [26_memo_componente](./26_memo_componente): Use React.memo para evitar re-renderizações desnecessárias em componentes filhos.
- [27_context_tema](./27_context_tema): Use a Context API para compartilhar o tema (claro/escuro) em toda a aplicação.
- [28_custom_hook_fetch](./28_custom_hook_fetch): Crie um custom hook useFetch que gerencia loading, data e error de uma requisição.
- [29_pokedex_basica](./29_pokedex_basica): Crie uma Pokédex consumindo a PokeAPI com paginação e detalhes de cada Pokémon.
- [30_portfolio_simples](./30_portfolio_simples): Crie um portfólio pessoal simples com React: seções de Sobre, Projetos e Contato.
