## 📂 Como usar

1. Escolha uma tecnologia.
2. Acesse a pasta correspondente ao seu nível (`Iniciante`, `Intermediario`, `Avancado`).
3. Leia o `README.md` do exercício e implemente a solução na mesma pasta.
4. Cada exercício tem sua própria pasta para manter a organização.
