# Nível 0: Muito Fácil (Sintaxe e Lógica Básica)

Neste nível você treinará a sintaxe fundamental da linguagem (JavaScript/TypeScript), declaração de variáveis e controle de fluxo simples.

---

### Exercício 0.1: Operações Básicas
**Objetivo:** Criar uma função `calcularOperacoes(a, b)` que receba dois números e retorne um objeto com a soma, subtração, multiplicação e divisão dos dois valores.

**Exemplo de Entrada:**
```javascript
calcularOperacoes(10, 2);
```

**Saída Esperada:**
```javascript
{
  soma: 12,
  subtracao: 8,
  multiplicacao: 20,
  divisao: 5
}
```

---

### Exercício 0.2: Par ou Ímpar
**Objetivo:** Criar uma função `verificarParImpar(numero)` que retorne a string `"Par"` se o número for par e `"Ímpar"` se for ímpar.

**Exemplo de Entrada:**
```javascript
verificarParImpar(7);
```

**Saída Esperada:**
```javascript
"Ímpar"
```

---

### Exercício 0.3: Formatador de Nome
**Objetivo:** Criar uma função `formatarNome(nome, sobrenome)` que receba o nome e sobrenome e retorne o nome completo formatado em *Title Case* (primeiras letras maiúsculas) e sem espaços extras nas pontas.

**Exemplo de Entrada:**
```javascript
formatarNome("  diego ", " rebua  ");
```

**Saída Esperada:**
```javascript
"Diego Rebua"
```
