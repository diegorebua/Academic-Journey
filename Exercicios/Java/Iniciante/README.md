# 🎯 Java — Iniciante

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01_hello_world_java](./01_hello_world_java): Escreva o programa 'Olá, Mundo!' e entenda a estrutura básica: classe, main, System.out.
- [02_tipos_primitivos](./02_tipos_primitivos): Explore todos os tipos primitivos (int, long, double, char, boolean) e seus wrappers.
- [03_estruturas_controle_java](./03_estruturas_controle_java): Use if/else, switch, for, while e do-while em exemplos práticos.
- [04_arrays_java](./04_arrays_java): Crie e manipule arrays unidimensionais e bidimensionais. Calcule média e maior/menor.
- [05_strings_java](./05_strings_java): Explore os métodos da classe String: split, join, replace, format, compareTo.
- [06_poo_basico](./06_poo_basico): Crie classes Conta e Cliente com atributos, construtores e métodos de depósito/saque.
- [07_heranca_java](./07_heranca_java): Implemente herança: Veiculo → Carro, Moto. Override de métodos.
- [08_interface_java](./08_interface_java): Crie uma interface Pagavel com métodos calcularJuros() e pagar(). Implemente com Boleto e CartaoCredito.
- [09_encapsulamento](./09_encapsulamento): Aplique encapsulamento com modificadores de acesso (private, protected) e getters/setters.
- [10_colecoes_java](./10_colecoes_java): Use ArrayList, LinkedList, HashSet e TreeSet. Compare desempenho e casos de uso.
- [11_maps_java](./11_maps_java): Use HashMap e TreeMap para mapear chave-valor. Contar frequência de palavras.
- [12_excecoes_java](./12_excecoes_java): Trate exceções com try-catch-finally. Crie exceções customizadas para domínio.
- [13_generics_java](./13_generics_java): Crie classes e métodos genéricos. Implemente um Container<T> e Pilha<T>.
- [14_enum_java](./14_enum_java): Crie Enums com atributos e métodos para representar os planetas do sistema solar.
- [15_record_java](./15_record_java): Use Records (Java 14+) para criar objetos de dados imutáveis.
- [16_optional_java](./16_optional_java): Use Optional<T> para evitar NullPointerException. Compare com abordagem tradicional.
- [17_lambda_simples](./17_lambda_simples): Escreva lambdas para Comparator, Runnable e interfaces funcionais simples.
- [18_streams_simples](./18_streams_simples): Use filter, map e collect na Stream API para processar uma lista de objetos.
- [19_local_date_time](./19_local_date_time): Manipule datas com LocalDate, LocalDateTime e DateTimeFormatter (Java 8+).
- [20_files_java](./20_files_java): Leia e escreva arquivos com java.nio.file.Files e Paths.
- [21_scanner_input](./21_scanner_input): Use Scanner para ler diferentes tipos de entrada do usuário no console.
- [22_string_builder](./22_string_builder): Compare String, StringBuilder e StringBuffer em operações de concatenação.
- [23_autoboxing](./23_autoboxing): Demonstre autoboxing e unboxing e os cuidados com NullPointerException e performance.
- [24_varargs](./24_varargs): Use varargs para criar métodos que aceitam número variável de argumentos.
- [25_nested_inner_class](./25_nested_inner_class): Explore inner classes, classes anônimas e static nested classes.
- [26_iterator_pattern](./26_iterator_pattern): Implemente o padrão Iterator em uma coleção customizada.
- [27_fibonacci_java](./27_fibonacci_java): Implemente Fibonacci com recursão simples, com memoização e com streams infinitas.
- [28_palindromo_java](./28_palindromo_java): Verifique palíndromo ignorando espaços, pontuação e maiúsculas.
- [29_calculadora_java](./29_calculadora_java): Crie uma calculadora com padrão Strategy: cada operação é uma classe separada.
- [30_jogo_adivinhar_java](./30_jogo_adivinhar_java): Crie o jogo de adivinhar o número com tentativas limitadas e dicas de maior/menor.
