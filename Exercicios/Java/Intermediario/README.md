# 🎯 Java — Intermediario

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01_streams_avancados](./01_streams_avancados): Use flatMap, reduce, groupingBy, partitioningBy e Collectors customizados.
- [02_stream_paralelo](./02_stream_paralelo): Compare Stream sequencial vs paralelo em processamento de listas grandes.
- [03_functional_interfaces](./03_functional_interfaces): Explore Function, Predicate, Consumer, Supplier, BiFunction e crie as suas próprias.
- [04_design_patterns_criacao](./04_design_patterns_criacao): Implemente Singleton, Factory Method, Abstract Factory, Builder e Prototype.
- [05_design_patterns_estrutura](./05_design_patterns_estrutura): Implemente Adapter, Decorator, Facade, Proxy e Composite.
- [06_design_patterns_comportamento](./06_design_patterns_comportamento): Implemente Strategy, Observer, Command, Iterator e Template Method.
- [07_spring_boot_crud](./07_spring_boot_crud): Crie uma API REST CRUD com Spring Boot, Spring Data JPA e banco H2 em memória.
- [08_spring_validation](./08_spring_validation): Adicione validação com Bean Validation (@Valid, @NotBlank, @Email) e erros customizados.
- [09_spring_security_basico](./09_spring_security_basico): Configure Spring Security com autenticação via usuário/senha em memória.
- [10_spring_jwt](./10_spring_jwt): Implemente autenticação JWT no Spring Boot com filtros de segurança customizados.
- [11_spring_data_avancado](./11_spring_data_avancado): Use @Query, Specifications e Criteria API para queries complexas no Spring Data.
- [12_spring_cache](./12_spring_cache): Configure cache com @Cacheable, @CacheEvict usando Redis como provider.
- [13_spring_events](./13_spring_events): Use ApplicationEventPublisher e @EventListener para desacoplar componentes.
- [14_spring_batch](./14_spring_batch): Processe um arquivo CSV de 1 milhão de linhas com Spring Batch.
- [15_spring_scheduler](./15_spring_scheduler): Use @Scheduled para criar tarefas agendadas no Spring Boot.
- [16_threads_executors](./16_threads_executors): Use ExecutorService, ThreadPoolExecutor, Callable e Future para paralelismo.
- [17_completable_future](./17_completable_future): Use CompletableFuture para encadear operações assíncronas sem bloquear.
- [18_virtual_threads](./18_virtual_threads): Use Virtual Threads (Java 21 Project Loom) para alta concorrência com código simples.
- [19_record_sealed_java](./19_record_sealed_java): Use Records e Sealed Classes para modelar dados algébricos de forma segura.
- [20_pattern_matching_java](./20_pattern_matching_java): Use Pattern Matching com instanceof e switch expressions (Java 17+).
- [21_httpclient_java](./21_httpclient_java): Use o java.net.http.HttpClient (Java 11+) para fazer requisições HTTP assíncronas.
- [22_jdbc_template](./22_jdbc_template): Use JdbcTemplate do Spring para executar queries SQL de forma segura (sem ORM).
- [23_mapstruct_mapper](./23_mapstruct_mapper): Use MapStruct para gerar mappers entre DTOs e entidades de domínio.
- [24_lombok_java](./24_lombok_java): Configure Lombok: @Data, @Builder, @RequiredArgsConstructor e seus impactos.
- [25_mock_junit](./25_mock_junit): Escreva testes com JUnit 5 e Mockito: @Mock, @InjectMocks, @Captor.
- [26_test_containers](./26_test_containers): Use Testcontainers para testes de integração com PostgreSQL, Redis e Kafka em containers.
- [27_jacoco_cobertura](./27_jacoco_cobertura): Configure JaCoCo para medir cobertura de testes e estabeleça limites mínimos.
- [28_actuator_monitoramento](./28_actuator_monitoramento): Configure Spring Boot Actuator com Micrometer, Prometheus e Grafana.
- [29_openapi_swagger_java](./29_openapi_swagger_java): Documente a API com SpringDoc OpenAPI e customize o Swagger UI.
- [30_flyway_migrations](./30_flyway_migrations): Use Flyway para gerenciar migrações de banco de dados de forma versionada.
