# 🎯 JavaScript — Iniciante

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01_hello_world](./01_hello_world): Escreva um script que imprime 'Olá, Mundo!' no console e depois peça o nome do usuário (via prompt ou readline) e cumprimente-o.
- [02_calculadora](./02_calculadora): Crie uma calculadora de operações básicas (soma, subtração, multiplicação, divisão) que leia dois números e o operador.
- [03_fizzbuzz](./03_fizzbuzz): Implemente o clássico FizzBuzz: para múltiplos de 3 imprima 'Fizz', de 5 'Buzz' e de ambos 'FizzBuzz'.
- [04_palindromo](./04_palindromo): Crie uma função que verifica se uma string é um palíndromo (ignora espaços e maiúsculas).
- [05_par_impar](./05_par_impar): Verifique se um número é par ou ímpar. Itere de 1 a 100 e imprima todos os pares.
- [06_fibonacci](./06_fibonacci): Gere os N primeiros números da sequência de Fibonacci.
- [07_fatorial](./07_fatorial): Calcule o fatorial de um número usando recursão e iteração. Compare os resultados.
- [08_inverter_string](./08_inverter_string): Inverta uma string sem usar .reverse() no array internamente (resolva manualmente).
- [09_maior_numero](./09_maior_numero): Dada uma lista de números, encontre o maior e o menor sem usar Math.max/min.
- [10_media_notas](./10_media_notas): Leia um array de notas de alunos, calcule a média e diga se o aluno foi aprovado (>=7).
- [11_remover_duplicatas](./11_remover_duplicatas): Remova os elementos duplicados de um array de diversas formas (Set, filter, reduce).
- [12_contar_vogais](./12_contar_vogais): Conte quantas vogais existem em uma string fornecida pelo usuário.
- [13_validar_email](./13_validar_email): Crie uma função que valida se uma string é um e-mail válido usando Regex.
- [14_converter_temperatura](./14_converter_temperatura): Converta temperaturas entre Celsius, Fahrenheit e Kelvin.
- [15_tabuada](./15_tabuada): Imprima a tabuada de um número de 1 a 10 fornecido pelo usuário.
- [16_anagrama](./16_anagrama): Verifique se duas palavras são anagramas uma da outra.
- [17_bubble_sort](./17_bubble_sort): Implemente o algoritmo Bubble Sort manualmente para ordenar um array.
- [18_contar_palavras](./18_contar_palavras): Conte quantas vezes cada palavra aparece em um texto e exiba as 5 mais frequentes.
- [19_numero_primo](./19_numero_primo): Crie uma função que verifica se um número é primo. Liste todos os primos até N.
- [20_jogo_adivinha](./20_jogo_adivinha): Crie o jogo de adivinhar o número: o computador escolhe um número aleatório e o usuário tenta adivinhar em até 7 tentativas.
- [21_pilha_fila](./21_pilha_fila): Implemente as estruturas de dados Pilha (Stack) e Fila (Queue) usando arrays e objetos.
- [22_matriz_transposta](./22_matriz_transposta): Dada uma matriz N×M, calcule e exiba a sua transposta.
- [23_conversor_moeda](./23_conversor_moeda): Crie um conversor de moeda simples (BRL → USD → EUR) com taxas fixas definidas no código.
- [24_mdc_mmc](./24_mdc_mmc): Calcule o MDC (Máximo Divisor Comum) e o MMC (Mínimo Múltiplo Comum) de dois números.
- [25_validar_cpf](./25_validar_cpf): Implemente a validação de CPF usando o algoritmo oficial dos dígitos verificadores.
- [26_roman_para_inteiro](./26_roman_para_inteiro): Converta números romanos para inteiros e vice-versa.
- [27_gerador_senha](./27_gerador_senha): Crie um gerador de senhas aleatórias com parâmetros: tamanho, incluir maiúsculas, números e símbolos.
- [28_compressao_rle](./28_compressao_rle): Implemente a compressão Run-Length Encoding (RLE) para uma string (ex: 'AAABBC' → '3A2B1C').
- [29_busca_binaria](./29_busca_binaria): Implemente a busca binária em um array ordenado e compare com busca linear.
- [30_linked_list](./30_linked_list): Implemente uma lista encadeada simples com operações de inserir no início, fim, remover e buscar.
